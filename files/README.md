# ЕГЭ · Русский язык: карточки, тест, рейтинг

Статичный сайт без сборки. Работает сразу: карточки с интервальным повторением, тест, тёмная тема, офлайн (PWA).
Рейтинг включается после настройки Supabase (бесплатно).

## 1. Опубликовать
1. Создайте репозиторий на GitHub, загрузите все файлы из этой папки.
2. На vercel.com (или netlify.com) войдите через GitHub, выберите репозиторий, нажмите Deploy.
   Либо GitHub Pages: Settings -> Pages -> ветка main.

## 2. Включить рейтинг (Supabase)
1. Зарегистрируйтесь на supabase.com, создайте проект (Free).
2. Authentication -> Sign In / Providers -> включите **Allow anonymous sign-ins**.
3. SQL Editor -> вставьте содержимое `supabase-setup.sql` -> Run.
4. Project Settings -> API: скопируйте **Project URL** и ключ **Publishable key** (sb_publishable_...) или, если его нет, **anon public**.
5. Вставьте их в `config.js`, сделайте коммит и push. Секретный ключ service_role в код не вставляйте никогда.

## Важно
- Ключ anon публичный по замыслу. Защиту даёт Row Level Security из SQL-файла: человек меняет только свою строку.
- Баллы отправляет браузер, поэтому хитрый пользователь может завысить свой счёт. Для учебного рейтинга это терпимо, лимит в SQL ограничивает максимум.
- Не просите настоящие имена: ученики могут быть несовершеннолетними. Кнопка «Удалить меня из рейтинга» уже есть.
- Добавили слова в `data.js`? Увеличьте лимит `score` в таблице.
- После изменений файлов поменяйте `V` в `sw.js` (например ege-v2), чтобы кеш обновился.
- Сверьте слова с официальным списком ФИПИ до публикации.
